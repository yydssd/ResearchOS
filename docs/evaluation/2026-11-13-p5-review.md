## Why 7 and 8 are deferred rather than silently patched

**Finding 7 is a redesign, not a regex edit.** The four-valued direction is an input contract for the merge gate, the cascade, the fixture labels and every measured number in the evaluation report. Fixing the negation list changes the direction distribution on all 1075 supported claims, which changes the merge gate, the claim count, the candidate-pair count and the whole §3–§4 table. Doing that inside a review would invalidate the evidence being reviewed. It needs its own measured cycle: write the failing cases, run the 20-paper hold-out, then re-transcribe every number. It is the first item of the P5 follow-up.

**Finding 8** touches supervisor error handling and event semantics, and needs a decision on whether a cross-run pair should abort a run or be refused-and-continued. That is a behaviour decision, not a mechanical fix.

Both are recorded as open items; neither is presented as met.

## TDD evidence: what git history can and cannot prove

All 11 implementation commits co-commit their tests. The plan contains "Step 1: write the failing test" and "Expected: FAIL" text, but every checkbox is still `- [ ]`.
